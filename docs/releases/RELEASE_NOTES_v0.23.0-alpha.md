## Overview

Home Finance OS v0.23.0-alpha introduces the first feature-flagged auth session shell.

The release keeps HFOS local-first by default while preparing the app shell for future account sign-in, sign-out, and session display flows.

---

## Planned Highlights

* Provider-neutral auth client factory.
* Auth session hook.
* Feature-flagged header auth control.
* Sign-in/sign-out adapter contracts.
