## Overview

Home Finance OS v0.28.0-alpha adds a feature-flagged Settings panel for auth prototype diagnostics.

The panel helps local QA inspect auth provider mode, session status, adapter type, membership count, and invitation count. It remains hidden in normal local-first builds.
