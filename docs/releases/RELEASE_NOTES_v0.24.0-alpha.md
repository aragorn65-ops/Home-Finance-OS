## Overview

Home Finance OS v0.24.0-alpha adds backend-facing contracts for future authenticated household persistence.

HFOS remains local-first. These contracts define the tenant, membership, invitation, authorization, and migration boundaries a future backend adapter must satisfy before remote data is enabled.

## Planned Highlights

* Remote household tenant contracts.
* Membership and invitation command contracts.
* Private-record authorization helper expansion.
* Migration draft, commit, and abort contracts.
