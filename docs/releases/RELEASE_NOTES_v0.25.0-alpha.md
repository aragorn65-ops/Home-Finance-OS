# Home Finance OS v0.25.0-alpha

## Auth Adapter Prototype

**Release Date:** TBD
**Status:** In progress
**Sprint:** Sprint 25

---

## Overview

Home Finance OS v0.25.0-alpha adds an in-memory auth and tenant adapter prototype.

The prototype exercises the auth, membership, invitation, tenant, and migration contracts without adding production login or remote persistence.

---

## Planned Highlights

* In-memory auth backend adapter.
* In-memory remote tenant repository.
* In-memory remote migration repository.
* Prototype-only state lifecycle.

---

## Deferred

* Production auth provider integration.
* Persistent backend storage.
* Household claim UI.
* Cloud sync.
