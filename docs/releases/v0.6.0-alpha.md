# HFOS v0.6.0-alpha

**Release Date:** July 13, 2026

---

# Overview

HFOS v0.6.0-alpha represents the first production-quality alpha release of Home Finance OS.

This milestone establishes the application's core architecture, shared component library, governance framework, household onboarding, dashboard infrastructure, and full Accounts CRUD module. The project now produces a clean production build and serves as the baseline for future feature development.
