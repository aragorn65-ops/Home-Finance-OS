## Household Claim Flow UI

**Release Date:** TBD
**Status:** In progress

## Overview

Home Finance OS v0.30.0-alpha adds the household claim flow UI for signed-in prototype users.

This feature allows local household owners to claim their household when authenticated, preparing the data for future remote migration while maintaining local-first availability.
