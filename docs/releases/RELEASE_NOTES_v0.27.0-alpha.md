## Overview

Home Finance OS v0.27.0-alpha adds read-only diagnostics for the feature-flagged auth prototype.

The diagnostics layer helps future QA UI and tests inspect whether auth is disabled, prototype-enabled, signed in, and backed by memberships or invitations without adding production backend behavior.
