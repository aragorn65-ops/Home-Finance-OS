# HFOS v0.3.0
## First Interactive Experience

**Release Date:** July 11, 2026

---

# Overview

HFOS v0.3.0 marks a major milestone in the project's evolution.

This release transforms HFOS from a collection of application screens into a complete interactive application with a guided onboarding experience, persistent household setup, startup routing, and a scalable application architecture.

The focus of this release was building the core foundation that future financial features will rely upon.

---

# Highlights

## ✨ First-Time User Experience

Introduced a complete household onboarding wizard.

Users are now guided through the initial setup process before entering the application.

Setup includes:

- Household Name
- Country
- Currency
- Time Zone
- Review & Confirmation

Household information is persisted locally and automatically restored on future launches.

---

## 🚀 Startup Flow

Added a dedicated Startup Page.

HFOS now automatically determines whether a household already exists.

Application flow:

```
Launch HFOS
        │
        ▼
   Startup Page
        │
        ├── Household Exists
        │        │
        │        ▼
        │   Dashboard
        │
        └── No Household
                 │
                 ▼
         Household Wizard
```

This provides a smoother and more professional first-run experience.

---

## 🏗 Application Architecture

Implemented nested routing using React Router.

New routing structure:

```
/
├── Startup
├── /household
└── /app
      ├── Dashboard
      ├── Help Center
      ├── Settings
      ├── Expenses
      ├── Savings
      ├── Reports
      └── About
```

AppShell now renders nested application routes using `<Outlet />`.

This architecture separates:

- Startup
- Onboarding
- Main Application

and provides a scalable foundation for future modules.

Previous routes:

```
/
/knowledge-center
/settings
```

```

/app/help-center
/app/settings
```
