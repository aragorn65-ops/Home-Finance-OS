**Release Date:** TBD

## Overview

Home Finance OS v0.22.0-alpha begins the implementation path for future account authentication by adding contracts and configuration only.

HFOS remains local-first. Account login, backend persistence, household sharing, and data migration are still deferred until the contracts are reviewed and the backend provider is selected.

---

## Planned Highlights

* Feature-flagged auth configuration.
* Auth session domain interfaces.
* User, membership, and invitation models.
* Authorization helper contracts.
* Backend adapter interfaces.
* Migration preview models.

---

## Deferred

* Production sign-in UI.
* Backend persistence.
* Local household claim flow.
* Remote migration writes.
* Multi-device sync.
