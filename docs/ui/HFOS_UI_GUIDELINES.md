# HFOS UI Guidelines

Version: 1.0

---

# Design Philosophy

HFOS should feel calm, trustworthy, and approachable.

The interface should reduce stress rather than add to it.

Every screen should help users make better financial decisions.

---

# Core Principles

1. Simplicity over complexity.

2. White space is functional.

3. Navigation should be obvious.

4. Every page has one primary action.

5. Consistency builds trust.

6. Build for everyday households.

# Empty States

Every empty state should answer:

"What should I do next?"

Never use "Coming Soon."

Always provide an action.
